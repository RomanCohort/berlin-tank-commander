# 柏林车长 - Berlin 1945 Tiger II Commander

二战柏林战役背景的文字冒险游戏，玩家扮演虎王坦克车长。

## 运行

```bash
python 柏林1945_虎王车长_系统版.py
```

## 项目文件

- `柏林1945_虎王车长_系统版.py` - 主游戏程序
- `文字冒险游戏_fixed8.py` - 文字冒险游戏引擎
- `sim_batch.py` / `sim_run.py` - 战斗模拟与批量测试
- `is2_test.py` / `test_tank_ally_ammo.py` - 单元测试
- `build_exe.py` - PyInstaller 打包脚本

## 注意

本项目仅供学习娱乐用途。
